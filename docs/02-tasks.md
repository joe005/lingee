# 任务

## 目标

让用户从意图创建任务，查看任务清单，按项目和阶段推进执行，并由人员审核产物。

## 入口与视图

- 任务页记住上次选择的看板／列表视图，刷新或重新进入时恢复；项目内任务清单的临时列表不覆盖该偏好。
- 协作开发 → 任务：按人员分配，默认只展示与当前用户相关的任务：当前阶段由我处理，或我负责的阶段已做完（无执行计划的任务看负责人）；他人负责、我未参与处理的任务不在列表中；仅工作区管理员可通过「负责人 → 全部」筛选查看他人任务，普通成员仅可查看自己参与的任务；阶段评审详情和交付产物按阶段处理权限隔离。可再按“我的任务、待处理”等范围查看。工作区管理员可查看工作区内全部任务。
- 列表页签按“轮到谁”划分：**待我处理**＝当前阶段由我开始、验收、回答 AI 提问或重试阻塞；**执行中**＝其余未完成任务（AI 执行中，或当前阶段由他人处理）；**已完成**＝任务整体完成，或我负责的阶段已做完（后续阶段由他人处理）。协作开发菜单徽标与“待我处理”同口径。
- 看板按状态分组时展示「待开始、执行中、待我处理、已完成」：所有需要人工验收、重试或回复的任务合并到「待我处理」，正常执行的任务归入「执行中」；卡片保留实际状态与查看产物／重试／回复按钮（待审核卡片不直接确认，点「查看产物」打开详情，在执行计划里查看产物后再确认）；待审核状态统一显示「待审核」，不把处理人姓名拼入状态名称。该归类不修改任务状态，「待我处理」不接受拖拽改状态。
- 管理板块项目下新建的研发任务进入同一份任务数据，按阶段执行人分配；管理项目可在项目筛选与新建任务的所属项目中选择，但不出现在协作开发的项目列表。
- 代码分支：项目配置了 Git 仓库和基准分支时，任务详情侧栏显示「代码分支」：`feature/<任务编号>` → 基准分支，状态为待拉取 / 开发中（开始执行时从基准分支拉取）/ 已合并（审核通过、任务完成后合并回基准分支）/ 已关闭。
- 项目卡片 → 任务清单：进入当前项目的全部任务，按最近更新时间倒序。
- 新建任务：普通任务页和项目任务清单均保留工具栏「新建」按钮；点击打开新建任务弹窗，默认聚焦可编辑的任务标题输入框，无论是否已选择项目都可直接录入标题；也可切换到智能创建，通过对话整理任务。所属项目、智能体团队、开发流程与优先级沿用统一下拉箭头和选项面板，类型及优先级可用方向键选择、回车确认、Esc 关闭。

## 关键流程

- 显示设置中的排序、分组选项支持在面板内滚动，滚动时保持打开；选择选项、点击外部或按 Esc 关闭，外部页面滚动或窗口缩放时关闭浮层以避免定位错位。

点击新建任务的「下一步」时，一次标红所有未填写的必填项，按标题、描述、所属项目、智能体团队、开发流程的顺序聚焦第一个缺失字段；填写有效内容后清除对应错误边框。

执行计划的阶段选择沿用任务信息页的下拉面板与键盘操作，执行人使用统一线性箭头；任务已启动后阶段和执行人保持禁用。

1. 对话输入框显示 `task-builder` 技能胶囊，在同一位置选择所属项目。
2. 输入任务意图后生成 Markdown 任务建议；用户可补充修改。
3. 选择项目后重新生成建议，点击“确认创建任务”才写入任务。
4. 新建任务的执行计划里每个节点有「AI 审核」开关（默认开启，可关闭），第二步底部有「保存任务」和「保存并开始」两个并排按钮（样式同管理的新建任务，后者保存后立即开始第一阶段，创建人不是第一阶段处理人时只创建并提示）。新建任务时选择智能体团队（项目不绑定团队；默认不选，选完团队才加载执行阶段，任务启动后团队锁定），「开发流程」（原任务类型）选完团队才加载：功能开发走团队的交付范围，缺陷修复只有开发实现、测试验证，与管理板块一致，执行人处理当前阶段并产出交付物。
5. 产物进入待审核；审核通过后流转下一阶段，最终完成任务。
6. 交付智能体的任务（如 T1001506）：开发成果「智能体配置」在任务详情的产物预览里直接打开智能体配置面板（与智能体开发会话同一份，可看角色设定、技能及其调用的 MCP 工具、上传知识；点「测试」另开测试会话，测完回到协作开发提交）。面板里点「提交」弹出「提交上架审核」确认，确认后任务的测试验证与提交上架一并完成，智能体变为「已提交」；验收页按钮为「通过并提交上架」，走同一个确认。
6. 任务详情「…」菜单只提供删除，不提供复制；详情不支持新发评论和子任务，已有评论仍显示在动态里。
7. 所有状态的任务均可删除，不根据执行阶段、流转记录或状态禁用；单条和批量删除均保留确认流程。已阻塞任务在列表和看板提供「重试」按钮（仅当前阶段处理人可操作）；点击复用已有阻塞会话继续执行，保留失败记录，成功后输出当前阶段的产物卡片并按原流程进入验收。
8. 执行计划每个阶段显示执行智能体（暂不显示处理人，避免被误解为由人执行）：智能体按阶段名称从任务所选的智能体团队中选取；阶段取自团队的交付路径，通用应用开发智能体团队为 4 个阶段：需求分析、系统设计、开发实现、测试验证；苍穹应用开发智能体团队为 3 个阶段：需求分析、开发实现、测试验证。两支内置团队按固定交付范围生成执行计划，阶段内的具体 WorkItem 动态拆分；自建团队保留其配置路径。缓存任务、当前阶段、阶段产物与会话阶段标记同步迁移，保留任务状态和历史。
   - 「智能体开发」阶段开始执行时，直接进入「智能体开发」界面（对话创建智能体、编辑配置、本地 / 云端测试、提交），不走通用任务会话。
   - 通用应用开发团队的「开发实现」产物是部署后的网站：阶段完成或待审核后，阶段下展示「网站预览」，打开后是带地址栏的可操作页面，铺满预览区。页面按项目名和任务标题判断业务主题：问卷类用问卷调研应用，工单类用工单管理系统应用（与应用开发里的工单管理系统同一页面），采购、报销、库存各有对应的演示网站（带侧栏、统计卡片、搜索与状态筛选、详情抽屉、新建），其他主题用任务产物里的演示列表数据；数据和操作只在当前页面生效。
9. 操作记录以任务自带的状态历史为准；历史里已有提交审核、完成或阻塞记录时，不再补推断记录。
10. 任务可指定由单个智能体执行（如「智能体开发」）：执行计划每个阶段都显示该智能体，执行会话、审核报告和任务卡片也以它代替任务的智能体团队。

10. 列表卡片展示状态徽标、编号、项目、标题、一句提示（轮到你开始执行「阶段」／智能体团队已提交「阶段」产物等待确认／AI 正在等你回答／执行受阻原因／当前阶段由某人处理）、任务类型与优先级标签，以及带阶段名称的进度条。右侧按钮随状态变化：交给AI执行、查看并验收产物、回答提问、重新执行、查看详情、查看产物；点击卡片其他区域或标题打开详情。
11. 列表卡片的「查看并验收产物」进入当前阶段的会话详情，与看板的会话入口保持一致，在会话中查看并验收产物。
12. 任务详情：底部主操作与列表同口径，只有轮到当前登录人才出现（交给AI执行／前往确认／回答提问／重试）；执行计划每行第一行为阶段名与状态，第二行为执行专家（不显示处理人），当前阶段的同类操作按钮放在行右侧；尚未开始的阶段不显示会话。

## 关键状态

`待交给AI执行` → `执行中` → `待验收` → `已完成`；执行失败进入`已阻塞`，保留旧数据并支持重试或修改。待交给 AI 执行和已阻塞任务在详情底部提供主要操作，分别用于进入 AI 执行会话和重新执行。

## 原型边界

任务和会话使用本地持久化模拟；专家执行、真实通知、服务端并发和审计留给后续实现。

## 下拉选择

普通单选字段复用共享下拉组件，统一箭头、面板、选中标记与单边框焦点状态；支持键盘选择、禁用项和空值选项（如「全部」或「无」）。现有搜索、多选选择器保留原有能力，归档页面不迁移。

任务工具栏的「新建」下拉与显示设置面板互斥，打开其中一个时关闭另一个及其子面板。

任务会话的执行阶段区域每次右键直接在 A、B 间切换，不弹出选项菜单：A 为原纵向列表，B 为参考 Ant Design 的无边框横向步骤条（节点与连线），显示阶段、处理人与状态并突出当前阶段；会话拖窄时按内容容器宽度动态压缩列宽与间距，达到最小可读列宽后局部横向滚动，不挤压正文；切到 B 时自动定位当前阶段。默认 A；B 直接显示全部步骤，不显示展开收起入口，切换会话后仍保持平铺；A 保留展开收起交互。仅改变当前页面展示，不修改执行计划。

新建任务填写内容或调整项目、优先级、负责人、执行计划后，点击关闭、取消、遮罩或按 Esc，显示「放弃更改？」与「关闭后，未保存的内容将丢失。」；默认聚焦「继续编辑」，保留全部输入，「放弃更改」关闭弹窗。未修改直接关闭，成功保存或提交智能创建不触发确认。

顶部操作提示按成功、警告、错误显示对应浅色背景；普通与成功提示默认 3 秒，警告 5 秒，错误 6 秒，长提示最多延长至 8 秒；悬停或聚焦暂停计时，并可手动关闭。

新建任务类型仅提供「需求」「缺陷」，默认选中「需求」，不提供空选项与「方案咨询」；复制或编辑旧任务时，缺陷保留原类型，未设置或旧咨询类型默认显示需求。

「新建」下拉仅保留「导入」，下载导入模板入口统一放在导入弹窗内。

协作开发任务入口默认展示列表：顶部保留任务、智能体、智能体团队与设置入口，状态页签使用胶囊样式，工具栏直接切换看板／列表；显示设置和新建下拉继续可用。任务卡片展示状态、编号、项目、标题、描述、类型、优先级与阶段进度，按状态提供「AI 执行」「验收产物」「重新执行」等现有操作；待审核和阻塞卡片的删除按钮复用删除确认，其他状态提供更多菜单。列表使用当前工作区的真实原型数据，数量与阶段数不固定为设计稿示例。

任务卡片的优先级标签直接使用功能配置中的名称，与新建、编辑和筛选选项一致，不追加「优先级」后缀。

任务页显示设置位于顶部导航右侧，与工作区设置入口区分；新建按钮及其下拉箭头统一高度，卡片更多／删除按钮常显，当前阶段名称居中对齐对应节点。

任务列表卡片已有「AI 执行」主按钮时，更多菜单不再重复提供「开始执行／发起会话」，保留复制、删除等其他操作。

最新版任务详情以任务概况、执行计划和操作记录分区展示，默认侧滑宽度 640px，保留宽度调整、字段编辑、附件、会话与产物操作；未开始任务也显示实际执行计划。新建任务弹窗按任务信息／执行计划两步展示，任务标题和描述通栏，项目、类型、优先级分列；添加节点入口位于计划表格上方。现有校验、智能创建、上一步、保存和未保存关闭确认继续有效，阶段与优先级来自功能配置。

任务列表的次要操作统一使用三个点下拉入口；待确认和阻塞卡片即使只有删除操作，也在菜单内展示，沿用删除权限与确认流程。

协作开发任务看板采用圆角分栏与卡片，卡片依次显示状态、编号与项目、标题、描述、类型和实际优先级，底部显示当前执行阶段与对应操作。开始、验收、重试、回复及查看产物沿用任务权限和流程；更多操作统一使用三个点入口，保留分组折叠、子任务展开与拖拽。按状态分组依次为待我处理、执行中、已完成；待开始和待规划并入待我处理，卡片保留实际状态。

任务卡片更多菜单点击菜单外区域（包括页面空白）时关闭，菜单内操作保持正常触发。

新建任务执行计划使用「AI 审核」开关，默认节点和新增节点默认开启；开启保存为无需人工确认，阶段完成后沿用自动审核并继续下一阶段的流程；关闭保存为需要人工确认。编辑既有计划保留已保存的审核设置。

执行计划中未选择执行人的控件显示为空并保留下拉箭头，不展示「待分配」占位文字；点击仍可选择项目成员。

看板卡片的三个点位于右上角，悬停或键盘聚焦卡片时展示；触摸设备常显。列表卡片仍保持原位置和常显方式。

看板中待确认任务统一显示「验收产物」按钮，点击进入产物验收预览，最终确认仍遵守阶段审核权限。

协作开发看板卡片始终展示已有任务描述，位于标题下方，单行超长省略，悬停可查看完整文字；不受旧版卡片描述隐藏偏好的影响。

新建任务执行计划步骤提供主按钮「保存并开始」，通过现有表单与执行人校验后创建任务并复用任务启动流程；「保存」为次要按钮，仅创建草案。编辑已有任务仍只保存修改，启动权限沿用当前阶段处理人规则。

新建任务的执行计划中，执行阶段名称为只读文字，不提供阶段名称下拉；执行人选择、AI 审核及添加／移除节点继续可用。

导航徽标与当前任务页「待我处理」数量同步：看板复用该状态分组计数，列表复用待处理页签计数，包含待开始任务并随任务变化刷新。

任务页看板／列表选项在当前浏览器本地缓存，刷新及重新进入任务入口恢复上次选择，不再强制重置为列表；项目内列表不会覆盖任务页视图偏好。

产物验收的「继续修改」退回当前阶段后进入任务已有会话，优先复用当前阶段会话，不重复登记修改会话。

看板和列表读取同一任务数据源并共用看板状态分组口径：待我处理、执行中、已完成。列表页签计数、列表内容和导航徽标均复用分组结果；切换展示方式保留筛选与搜索，不改变任务集合，新增、修改、删除同步反映到两个视图。

看板与列表共用状态按钮配置及点击处理：AI 执行、验收产物、重新执行、回复、查看产物和查看详情，两种展示的文案、入口与权限行为一致。

看板所有状态的任务卡片点击均打开任务详情；卡片内操作按钮独立处理执行、会话或产物操作，避免点击卡片直接进入会话。Ctrl / Command 点击继续用于多选。
