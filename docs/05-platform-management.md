# 管理平台

## 目标与管理范围

管理平台提供两种管理域：

- **金蝶官方管理**：原厂管理员维护官方数字员工和专家团，内容不绑定租户。
- **租户管理**：租户管理员维护本企业自建数字员工和专家团，只能访问自己的 `tenantId` 数据。

平台管理是发布源；协作空间和客户端是消费端。平台发布不会直接改写个人开发稿或已安装个人资产。

## 数据对象与隔离

| 对象 | 关键字段 | 隔离规则 |
| --- | --- | --- |
| 资产元数据 | `assetId`、来源、`tenantId`、状态、当前版本 | 官方 `tenantId=null`；租户资产按 `tenantId` 过滤；个人稿按创建人过滤。 |
| 版本快照 | `versionId`、版本号、快照、更新说明、作者、时间 | 只增不改；导入已有资产生成新版本。 |
| 审核单 | `reviewId`、目标租户、提交快照、审核状态、原因 | 租户管理员只能审核本租户；原厂审核官方提交。 |
| 安装记录 | `assetId`、客户端用户、安装版本 | 与平台草稿、发布版本分离，更新失败不覆盖旧记录。 |

原型对应存储键为 `lingee.platform.meta.v1`、`lingee.platform.versions.v1`、`lingee.platform.reviews.v1`、`lingee.platform.installed.v1`；正式实现需由服务端鉴权和数据库约束保障隔离。

## 角色与权限

| 能力 | 原厂管理员 | 租户管理员 | 提交人/个人开发者 | 普通租户成员 |
| --- | --- | --- | --- | --- |
| 导入/编辑资产 | 官方范围 | 本租户范围 | 本人草稿 | 无 |
| 查看审核单 | 官方范围 | 本租户范围 | 本人提交 | 无 |
| 通过/驳回 | 官方范围 | 本租户范围 | 无 | 无 |
| 上架/下架 | 官方范围 | 本租户范围 | 无 | 无 |
| 历史版本/导出 ZIP | 官方范围 | 本租户范围 | 本人资产 | 已发布可见 |
| 管理更新设置 | 全局默认 | 本租户默认 | 个人客户端偏好 | 个人客户端偏好 |

无租户账号不可进入租户管理；原厂管理不提供租户选择器。页面按角色隐藏入口只是体验优化，接口仍需校验角色和 `tenantId`。

## 管理流程

### 原厂官方内容

导入模拟包 → 解析/扫描 → 选择头像、名称、简介 → 确认导入为草稿 → 编辑后提交审核 → 原厂审核通过 → 自动生成递增版本并上架 → 客户端卡片显示官方来源和更新提示。支持历史版本、导出 ZIP 和下架；下架不删除历史版本。

### 租户自建内容

个人开发者从协作空间提交快照 → 系统写入目标租户审核单 → 租户管理员查看完整简介、技能、成员和更新说明 → 通过则生成企业自建版本并上架，驳回则要求原因并回到草稿 → 成员在客户端点击“+”安装。专家团发布前校验数字员工成员版本，安装时自动补齐缺失依赖。

## 版本与审核状态

- 新资产：导入后为草稿，首次提交通过后生成 `V1`。
- 已有资产：导入或提交更新必须填写更新说明，系统生成下一个只读版本。
- 状态：草稿 → 待审核 → 已上架；驳回回到草稿；已上架可下架。
- 审核通过和驳回在同一操作行；只有选择驳回后才展示必填原因。
- 驳回不新增状态：被驳回的审核单在“草稿”和“全部”中显示“已驳回”卡片，点开可看驳回原因；重新提交后旧卡片消失。
- 驳回同时作为一条事件记入该资产的“历史版本”（版本号、原因、审核人、时间、提交人和提交说明），已发布版本照常可导出。
- 待审核数量为 0 时不显示红色提醒。
- 审核使用提交快照，审核期间个人稿继续可编辑；通过后个人稿与企业版本并存。

## 管理端交互

列表仅保留搜索框和状态页签，卡片固定尺寸，展示头像、名称、来源、版本、简介、状态和更新时间。点击导入先打开对话框，在对话框内选择 ZIP 包，再进入模拟解析与扫描；详情提供查看历史版本、导出 ZIP、提交审核、通过、驳回、上架/下架等按状态显示的操作。更新设置集中放在“设置”页签，可配置发现新版本时是否提示或自动更新数字员工与专家团。

## 用户旅程

原厂管理员进入管理平台 → 导入并确认官方数字员工 → 编辑并提交审核 → 通过后上架 → 客户端用户看到官方新版本提示并更新。租户管理员进入租户管理 → 查看本租户待审核 → 通过/驳回并记录原因 → 上架企业资产 → 租户成员从更多数字员工/专家团点击“+”安装，团队自动安装缺失成员 → 后续按版本提示更新。

## 原型边界

当前解析、扫描、审核、发布、导出、安装和更新均由浏览器本地数据模拟；不读取真实 ZIP、不提供真实云端服务、组织身份认证、对象存储和安全扫描。真实实现必须补充服务端鉴权、审计日志、包签名、并发控制和租户级数据访问策略。
