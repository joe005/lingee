# 管理

## 目标与范围

管理板块面向经营管理者，用「管理项目」组织经营目标、风险与待决策事项。本期按演示范围只开放「项目」：项目列表与项目详情。决策中心、AI组织保留菜单入口，点击提示「不在本次演示范围」。

## 入口

- 侧栏顶部频道页签：工作 / 管理 / 开发。切到「管理」后侧栏只显示管理菜单，主区打开项目列表；切回「开发」恢复离开前的开发菜单；「工作」打开首页。
- 管理菜单：决策中心、AI组织、项目；下方「我的项目」为常用提问（演示提示），「项目」目录树按项目展开，点子项进入对应项目详情。
- 地址：`/manager?m=ceo-projects`，项目详情追加 `&proj=<项目 ID>`，刷新后还原。

## 数据业务关系

| 对象 | 关键字段 | 关系与规则 |
| --- | --- | --- |
| 管理项目 | 名称、目标、负责人、周期、里程碑、风险数、待决策数、进度 | 与协作开发的项目分开存放，不出现在开发板块项目列表。 |
| 项目成员 | 人员 ID、项目角色（产品 / 开发 / 测试） | 人员与开发板块共用同一份人员数据；从灵基人员搜索加入的人员会写入共享人员数据，开发板块同样可见。 |
| 项目任务 | 编号、执行人、截止、里程碑、状态、执行计划 | 归属管理项目；可挂里程碑。通用任务只在管理板块；研发任务写入开发板块的任务数据，与开发板块共用，任务当前处理人为第一阶段执行人，在开发板块「任务」中由对应人员处理，处理进展回到管理项目详情。 |
| 议题 | 标题、来源、状态、关联任务、决策记录 | 任务行「升级为议题」生成，汇总在详情右栏「议题」；风险议题关联被阻塞的任务，由项目负责人、项目管理员或系统管理员批准 / 驳回。 |
| 项目知识库 | 标题、类型、来源任务 | 任务产物归档后进入；演示项目暂无归档。 |
| 智能体团队 / 项目智能体 | 团队 ID、智能体 ID | 复用智能体与智能体团队基础数据；项目不绑定智能体团队，新建研发任务时才选团队；详情右栏只显示项目智能体。 |

## 关键流程

1. 项目首页：暂时只展示开发类项目（含研发任务）和用户自己新建的项目（含空白类），非开发类的预置演示项目不出现在标题计数、「待你处理」和「全部项目」里；灰画布上标题「项目 N」与右上「新建项目」；「待你处理」列出分给我的未完成任务（不含待审核）和我能管理的项目里待处理的议题，默认显示 3 条，超过时「全部 / 收起」展开，没有时显示「暂无待办」，点一行进入对应项目；「全部项目」按最近修改时间倒序（新建、重命名、改目标、成员或仓库等都会更新修改时间；没改过的演示项目排在后面），带搜索框（按项目名或负责人过滤），卡片展示项目名、目标摘要、负责人头像与姓名及风险 / 待决策标签（无问题时「运行正常」），点卡片进入详情；底部「问灵基」输入框为演示提示。
2. 新建项目：先选「项目类型」（通用项目 / 开发项目，默认通用项目；开发项目不再区分通用 / 苍穹）；选通用项目时再选模板（空白、预算目标制定、月度经营分析等），开发项目没有模板；选项横向排列、自动换行且不分组，类型与详情在同一弹窗展示，选择类型或模板后自动聚焦项目名称输入框，可直接录入；填写名称和目标或项目指令；「项目成员」默认只有创建人（项目负责人，不可移除），点「＋ 邀请成员」打开与项目详情相同的「邀请成员」弹窗，勾选人员并选择「项目管理员」或「成员」后确定，已选成员以标签显示（管理员带标记）、可移除；创建后岗位按岗位标签默认推断；开发项目以普通字段标签显示「描述」（无页签选中样式，不预填默认值），隐藏项目指令页签与字段，创建时不保存项目指令；切回通用项目后恢复「目标 / 项目指令」页签。弹窗内不设项目智能体，也不选智能体团队（团队在新建研发任务时再选）。开发项目必须填写 Git 地址、通过与新建任务复用的下拉组件选择基准分支（main / master / develop 或自定义，支持键盘选择）和智能体团队（默认「请选择智能体团队」，只列内置的通用 / 苍穹应用开发智能体团队，不含自建团队）。负责人默认当前登录用户。
3. 项目详情：面包屑返回列表；主栏「计划与任务 / 动态」，右栏「议题 / 项目概览 / AI 贡献 / 知识库 / 项目智能体」。项目概览的「进度」演示项目取预设百分比，其余项目按任务完成数计算（不含已取消，如「100% · 任务 1/1」），没有任务时按已过期里程碑，都没有为 0%；周期未设置时显示「未设置」。
   右栏「议题」点开列出风险与待决策：风险议题带「查看任务」，直接打开被阻塞的任务；有管理权限的人可「批准」或「驳回」，批准后被阻塞的任务恢复执行，项目卡片上的风险与待决策标记同步减少，决策写入「动态」。含研发任务且已有代码与审核记录的项目，项目概览下方有「AI 贡献」卡：AI 代码生成率（合入代码中智能体生成的行数占比）、AI 提交占比（代码提交中由智能体发起的占比）、一次审核通过率（已审核阶段中首次审核即通过的占比），悬停可看分子分母；原型为演示数据。
   「动态」页签是活动流：标题与说明、右侧搜索（任务、议题、智能体、操作人）和「导出」（演示提示）；来源胶囊「全部 / 人工 / 智能体 / 风险 / 系统」带数量；下方「全部任务 + 各任务名」页签按任务过滤；时间线每条显示时间、动作标签、操作人、任务编号与名称，以及一句加粗的动作摘要。任务创建、开始执行、审核通过和风险决策记为人工，智能体按阶段完成与提交待审核记为智能体（研发任务每完成一个阶段一条），知识库归档记为智能体，变更为已阻塞记为风险，其余状态变更记为系统；最多显示 60 条，进入详情时过滤条件复位。
   详情页中间的「计划与任务」主区占满可用宽度（不再限制最大宽度），右栏固定 300px；宽屏下页面本身不滚动，任务列表 / 动态在主卡片内滚动（表头固定），右栏始终在视野内；主卡片右上角的收起按钮可收起右栏，主区随之占满整行，再点展开。标题右侧「邀请成员」为品牌色描边按钮。
   列表与详情底部固定「问灵基」输入框（对齐对话输入框：更宽更高，Enter 发送、Shift + Enter 换行，内容区滚动时它不动）。
4. 计划与任务：列表列为序号、任务、关联会话、执行智能体、协作人、截止时间、状态、操作；筛选栏的人员下拉为「全部协作人」（负责人与协作人都算）；操作列为编辑图标和「···」菜单：查看详情、编辑任务（已完成的任务不能编辑，编辑图标与菜单项置灰；其余打开「编辑任务」弹窗，复用新建任务界面并带入已有内容，底部为「保存修改」；研发任务同样展示执行计划，未启动时可调整，已启动后只读）、新建子任务、启动、强制启动、作废任务、删除任务；不满足条件的项置灰并提示原因（启动限待规划 / 待开始，强制启动另含已阻塞，作废限未完成未取消，删除规则见第 9 条）。状态筛选（全部、待处理、进行中、待验收、已完成，带任务数，进入项目默认选中「全部」；筛选栏一行依次为状态下拉、负责人、排序、搜索和「新建任务」）、搜索编号或任务名、按负责人筛选、排序；视图切换为列表（按里程碑分组，可折叠）、里程碑卡片、甘特图。点任务行在右侧滑出任务详情抽屉（宽约 840px，左侧大圆角）：标题行右侧是执行方式、任务编号和状态标签；执行阶段每行显示执行该阶段的智能体（无智能体时显示处理人）；分区依次为执行概览、任务描述、验收标准、执行阶段、进展记录；底部为编辑和更多操作（不含任务关系、更多信息分区，也不提供报完成、新建子任务，这些在任务执行时再构建）。
   甘特图：横轴为时间（跨度 10 周内按周、更长按月显示刻度），按里程碑分组，里程碑用菱形标在日期上，竖线标出今天；每个任务一条横条，从创建日画到截止日，颜色对应状态（已完成 / 执行中 / 待审核 / 已阻塞 / 待开始），未设截止日的任务画到今天（已完成的画到更新日）并用虚边表示，已逾期的条尾标红；点任务行或横条打开任务详情，底部有图例。
4.1 研发任务：项目详情主栏页签为「计划与任务 / 研发任务 / 动态」。开发类项目（含研发任务）默认打开「研发任务」，只显示「研发任务 / 动态」，不显示「计划与任务」；其他项目（如空白类）只显示「计划与任务 / 动态」，不显示「研发任务」。「计划与任务」只列通用任务。研发任务页签显示任务数；表格样式与计划与任务一致：编号、任务（带「轮到谁处理」提示）、当前处理人、进展（团队随任务所选，不单列执行主体）（已完成阶段 / 总阶段）、状态（同一套状态标签）和操作列（编辑图标与「···」菜单：查看详情、编辑任务、作废任务、删除任务；研发任务不提供启动与新建子任务，执行与拆分在开发板块完成）；已完成的任务当前处理人显示「—」；点任务行在右侧打开任务详情。筛选栏为状态下拉（全部、待处理、进行中、待验收、已完成，带任务数，口径与计划与任务一致）、搜索编号或任务名和右侧「新建任务」，不设阶段分布、范围页签和底部说明；「新建任务」打开带执行计划的「新建研发任务」弹窗。
5. 新建任务：「核心信息」填任务名、描述、协作人、计划时间（中文日历选择，显示与保存为 YYYY-MM-DD，清除 / 今天可快捷设置）、AI 验收、验收标准；不再选择任务类型：「计划与任务」的「新建任务」建通用任务，「研发任务」的「新建研发任务」建研发任务并编辑执行计划；父任务、前序任务只列同类任务；研发任务执行计划（与开发板块新建任务一致：先在「智能体团队」下拉选团队（默认不选，选完才加载阶段，任务启动后锁定），选完团队才加载「开发流程」下拉（功能开发 / 缺陷修复，默认功能开发；缺陷修复固定开发实现、测试验证两阶段）；任务名、智能体团队、开发流程是必填项，标签旁用红色 * 标出，执行阶段取自该团队的交付路径、智能体按阶段匹配，每个节点设置自动审核与审核人，审核人按项目角色默认匹配，保存前每个节点都要有审核人），选中研发任务时隐藏附件 / 选择智能体 / 选择模型、协作人、计划时间、AI 验收和验收标准。「补充信息」页签：通用任务设置父任务、产物归档目录、启动方式、前序任务、里程碑标记、关联指标和子任务；研发任务只保留「是否里程碑」（新建和编辑一致）。弹窗底部：新建通用任务为「取消」「保存任务」「保存并启动」（保存后进入待开始，「保存并启动」直接进入执行中）；研发任务和编辑任务只有「取消」和「保存」/「保存修改」：研发任务保存后为待开始，分配给第一阶段执行人，不立即执行，由执行人在开发板块「任务」中开始。任务列表的「执行人」与任务详情的「当前处理人」都取当前阶段执行人。研发任务行「···」→「在开发板块打开任务」打开开发板块的任务详情。
6. 成员与权限：标题右侧的「项目成员」图标打开「成员与权限」弹窗，改动即时生效，只有成员一栏（不设项目智能体，智能体通过团队绑定）。「成员 N个」：搜索姓名，页签「全部 / 负责人 / 管理员 / 成员 / 参与人」带人数（参与人是任务里出现但不在成员列表里的人，没有时不显示数字），每页 6 人分页；每行显示头像、姓名、角色标签（项目负责人 / 项目管理员 / 成员），管理员和成员行有编辑图标，菜单里可设为项目管理员或成员、调整岗位（产品 / 开发 / 测试，用于任务执行人默认匹配）、移除成员（二次确认）。右上「邀请」（及标题右侧的「邀请成员」按钮）打开「邀请成员」：人员列表可搜索，已在项目中的人不再出现，勾选一人或多人，选择本次加入的项目内角色——「项目管理员」（管理项目日常：目录、权限、知识与成员维护，拥有与负责人相同的管理权限）或「成员」（默认，参与协作、按权限查看进展），点「确定」一次加入，未勾选人员时「确定」禁用。成员的维护仅项目负责人、项目管理员或系统管理员可用，其他人只读。
7. 重命名项目：项目详情标题右侧「···」→「重命名项目」，名称必填、不超过 60 字、不能与其他管理项目重名；保存后标题、面包屑、项目卡片、侧栏目录树及开发板块里的项目名同步更新。
8. 项目设置：项目详情「项目设置」图标进入「项目设置」页（左上箭头返回详情），分「目标」「项目指令」「功能页面」三张卡片，各自「编辑」后就地改文字、保存或取消（目标不能为空，保存后同步项目卡片描述；目标超过三行折叠，可展开 / 收起）；「功能页面」列出项目详情的页签（计划与任务、研发任务（仅开发项目）、动态和自定义页面），每行有上移 / 下移按钮和显示复选框，勾选即显示、取消即隐藏，改动即时保存并同步到详情页签顺序；至少保留一个页面（只剩一个时复选框禁用）；底部输入名称点「添加自定义页面」（最多 12 字、不可重名）新增页签，自定义页面带「自定义」标记和删除按钮，页面内容为占位（原型演示）；默认开发项目显示研发任务和动态、其他项目显示计划与任务和动态，进入详情默认打开第一个显示的页面；无管理权限者只读。开发项目另有「代码仓库」卡片，「编辑」打开代码仓库弹窗，可修改 Git 地址与基准分支（右栏「项目概览」显示两者）。仅项目负责人、项目管理员或系统管理员可编辑，其他人只读。配置后，项目下的开发任务按分支开发：任务分支为 `feature/<任务编号>`，开始执行前为「待拉取」，开始执行时从基准分支拉取（「开发中」），审核通过、任务完成后合并回基准分支（「已合并到 <基准分支>」），任务取消则「已关闭」不合并。开发板块任务详情显示「代码分支」（管理端任务详情抽屉不显示），状态按任务状态推导，原型不接真实 Git。
9. 删除未开始的任务：任务行「···」（及任务详情底部「···」）的「删除任务」，仅待规划 / 待开始且没有状态流转的任务可删，二次确认后删除，并清除其他任务对它的父任务、前序引用；研发任务沿用开发板块规则（待开始且未经历任何阶段）。仅项目负责人、系统管理员或任务创建人可见。行菜单浮在列表卡片之上，不被卡片边界裁切，空间不足时向上展开。
10. 删除项目：项目详情标题右侧「···」→「删除项目」，二次确认后删除；项目下的任务（管理任务与开发板块任务）和议题一并删除，不校验已有任务，返回项目列表，侧栏目录树同步隐藏该项目。

## 状态与异常

- 任务：待规划 / 待开始 / 已阻塞计入「待处理」；执行中、待审核、已完成、已取消按原状态显示。
- 未填任务名、研发任务无有效阶段、开发类项目缺 Git 地址、研发任务未选智能体团队时，就近提示并不保存。
- 右栏「会话权限（演示）」关闭后，任务行不再提供「在开发板块打开任务」，知识库只展示归档元数据。
- 项目成员：仅项目负责人、项目管理员或系统管理员可维护，其他人只读；项目负责人不能移除；有未完成任务（执行人、协作人或阶段执行人）的成员不能移除；项目至少保留 1 名成员；新加入成员的岗位按岗位标签默认推断，可在编辑菜单里调整。
- 重命名、删除项目：仅项目负责人或系统管理员可操作；不校验项目下是否已有任务，删除时任务一并清理，确认弹窗提示任务数量；确认时再次校验权限，变化则取消删除。
- 本地存储不可用时提示保存失败，不写入半条项目。

## 原型边界

管理项目、任务、议题保存在浏览器本地；项目管理员、项目目标与指令随项目保存在本地，项目管理员目前只影响项目管理权限；代码分支的拉取与合并只做状态展示。编辑任务、问灵基、在开发板块打开任务为演示提示，未接入真实执行与权限服务。

## 下拉选择

普通单选字段复用共享下拉组件，统一箭头、面板、选中标记与单边框焦点状态；支持键盘选择、禁用项和空值选项（如「全部」或「无」）。现有搜索、多选选择器保留原有能力，归档页面不迁移。
