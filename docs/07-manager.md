# 管理

## 目标与范围

管理板块面向经营管理者，用「管理项目」组织经营目标、风险与待决策事项。本期按演示范围只开放「项目」：项目列表与项目详情。决策中心、AI组织保留菜单入口，点击提示「不在本次演示范围」。

## 入口

- 侧栏顶部频道页签：工作 / 管理 / 开发。切到「管理」后侧栏只显示管理菜单，主区打开项目列表；切回「开发」恢复离开前的开发菜单；「工作」打开首页。
- 管理菜单：决策中心、AI组织、项目；下方「我的项目」为常用提问（演示提示），「项目」目录树按项目展开，点子项进入对应项目详情。
- 地址：`/manager?m=ceo-projects`，项目详情追加 `&proj=<项目 ID>`，刷新后还原。

## 数据业务关系

| 对象 | 关键字段 | 关系与规则 |
| --- | --- | --- |
| 管理项目 | 名称、目标、负责人、周期、里程碑、风险数、待决策数、进度 | 与协作开发的项目分开存放，不出现在开发板块项目列表。 |
| 项目成员 | 人员 ID、项目角色（产品 / 开发 / 测试） | 人员与开发板块共用同一份人员数据；从灵基人员搜索加入的人员会写入共享人员数据，开发板块同样可见。 |
| 项目任务 | 编号、执行人、截止、里程碑、状态、执行计划 | 归属管理项目；可挂里程碑。通用任务只在管理板块；研发任务写入开发板块的任务数据，与开发板块共用，任务当前处理人为第一阶段执行人，在开发板块「任务」中由对应人员处理，处理进展回到管理项目详情。 |
| 议题 | 标题、来源、状态 | 任务行「升级为议题」生成，汇总在详情右栏「议题」。 |
| 项目知识库 | 标题、类型、来源任务 | 任务产物归档后进入；演示项目暂无归档。 |
| 智能体团队 / 项目智能体 | 团队 ID、智能体 ID | 复用智能体与智能体团队基础数据；在详情右栏「智能体团队 → 管理」增删。 |

## 关键流程

1. 项目首页：灰画布上标题「项目 N」与右上「新建项目」；「待你处理」列出分给我的未完成任务（不含待审核）和我能管理的项目里待处理的议题，默认显示 3 条，超过时「全部 / 收起」展开，没有时显示「暂无待办」，点一行进入对应项目；「全部项目」带搜索框（按项目名或负责人过滤），卡片展示项目名、目标摘要、负责人头像与姓名及风险 / 待决策标签（无问题时「运行正常」），点卡片进入详情；底部「问灵基」输入框为演示提示。
2. 新建项目：选择模板（空白、开发项目、预算目标制定等；开发项目不再区分通用 / 苍穹），选择模板后自动聚焦项目名称输入框，可直接录入；填写名称和目标或项目指令；开发项目模板以普通字段标签显示目标（无页签选中样式，不预填默认值），隐藏项目指令页签与字段，创建时不保存项目指令；切回其他模板后可填写项目指令。弹窗内不设项目智能体，创建后在详情右栏「智能体团队 → 管理」增删。开发项目模板必须填写 Git 地址、通过与新建任务复用的下拉组件选择基准分支（main / master / develop 或自定义，支持键盘选择）和智能体团队（默认通用应用开发智能体团队，可改选）。负责人默认当前登录用户。
3. 项目详情：面包屑返回列表；主栏「计划与任务 / 动态」，右栏「议题 / 项目概览 / 知识库 / 智能体团队」。项目概览的「进度」演示项目取预设百分比，其余项目按任务完成数计算（不含已取消，如「100% · 任务 1/1」），没有任务时按已过期里程碑，都没有为 0%；周期未设置时显示「未设置」。
   「动态」页签是活动流：标题与说明、右侧搜索（任务、议题、智能体、操作人）和「导出」（演示提示）；来源胶囊「全部 / 人工 / 智能体 / 风险 / 系统」带数量，右侧「关键动作」下拉（任务创建、任务状态变更、知识库归档）；下方「全部任务 + 各任务名」页签按任务过滤；时间线每条显示时间、动作标签、操作人、任务编号与名称，以及一句加粗的动作摘要。任务创建记为人工，状态变更记为系统（变更为已阻塞记为风险），知识库归档记为智能体；最多显示 60 条，进入详情时过滤条件复位。
   详情页中间的「计划与任务」主区占满可用宽度（不再限制最大宽度），右栏固定 300px。
   列表与详情底部固定「问灵基」输入框（对齐对话输入框：更宽更高，Enter 发送、Shift + Enter 换行，内容区滚动时它不动）。
4. 计划与任务：状态筛选（全部、待处理、进行中、待验收、已完成，进入项目默认选中「待处理」；页签为分段样式，工具栏依次为负责人、排序、搜索和「新建任务」）、搜索编号或任务名、按负责人筛选、排序；视图切换为列表（按里程碑分组，可折叠）、里程碑卡片、甘特图。点任务行在右侧滑出任务详情抽屉（宽约 840px，左侧大圆角）：标题行右侧是执行方式、任务编号和状态标签；分区依次为执行概览、任务描述、验收标准、代码分支（开发任务）、执行阶段、任务关系、进展记录、更多信息（发起人、验收方式、启动方式、产物归档目录、关联指标、完结时间），其中「任务关系」「更多信息」可折叠 / 展开；底部为报完成、编辑、新建子任务和更多操作。
   甘特图：横轴为时间（跨度 10 周内按周、更长按月显示刻度），按里程碑分组，里程碑用菱形标在日期上，竖线标出今天；每个任务一条横条，从创建日画到截止日，颜色对应状态（已完成 / 执行中 / 待审核 / 已阻塞 / 待开始），未设截止日的任务画到今天（已完成的画到更新日）并用虚边表示，已逾期的条尾标红；点任务行或横条打开任务详情，底部有图例。
5. 新建任务：「核心信息」填任务名、描述、协作人、计划时间（中文日历选择，显示与保存为 YYYY-MM-DD，清除 / 今天可快捷设置）、AI 验收、验收标准；含研发任务的项目可选研发任务并编辑执行计划（与开发板块新建任务一致：执行阶段取自交付智能体团队的交付路径、智能体按阶段匹配，每个节点设置自动审核与执行人，执行人按项目角色默认匹配，保存前每个节点都要有执行人）。「补充信息」设置父任务、产物归档目录、启动方式、前序任务、里程碑标记、关联指标和子任务。通用任务「保存任务」进入待开始、「保存并启动」进入进行中；研发任务只有「保存并分配」：保存后为待开始，分配给第一阶段执行人，不立即执行，由执行人在开发板块「任务」中开始。任务列表的「执行人」与任务详情的「当前处理人」都取当前阶段执行人。研发任务行「···」→「在开发板块打开任务」打开开发板块的任务详情。
6. 成员与权限：标题右侧的「项目成员」图标打开「成员与权限」弹窗，左右两栏，改动即时生效。左栏「成员 N个」：搜索姓名，页签「全部 / 负责人 / 管理员 / 成员 / 参与人」带人数（参与人是任务里出现但不在成员列表里的人，没有时不显示数字），每页 6 人分页；每行显示头像、姓名、角色标签（项目负责人 / 项目管理员 / 成员），管理员和成员行有编辑图标，菜单里可设为项目管理员或成员、调整岗位（产品 / 开发 / 测试，用于任务执行人默认匹配）、移除成员（二次确认）。右上「邀请」（及标题右侧的「邀请成员」按钮）打开「邀请成员」：人员列表可搜索，已在项目中的人不再出现，勾选一人或多人，选择本次加入的项目内角色——「项目管理员」（管理项目日常：目录、权限、知识与成员维护，拥有与负责人相同的管理权限）或「成员」（默认，参与协作、按权限查看进展），点「确定」一次加入，未勾选人员时「确定」禁用。右栏「智能体 N个」：搜索，右上「添加」从智能体列表选择装配到项目，点开某个智能体可设置功能权限（对话调用、读取项目知识库、写入任务产物）或移除，没有时显示「暂无已装配智能体」，与详情右栏「智能体团队 → 智能体」是同一份数据。成员和智能体的维护仅项目负责人、项目管理员或系统管理员可用，其他人只读。
7. 重命名项目：项目详情标题右侧「···」→「重命名项目」，名称必填、不超过 60 字、不能与其他管理项目重名；保存后标题、面包屑、项目卡片、侧栏目录树及开发板块里的项目名同步更新。
8. 项目设置：项目详情「项目设置」图标进入「项目设置」页（左上箭头返回详情），分「目标」「项目指令」两张卡片，各自「编辑」后就地改文字、保存或取消（目标不能为空，保存后同步项目卡片描述；目标超过三行折叠，可展开 / 收起）；开发项目另有「代码仓库」卡片，「编辑」打开代码仓库弹窗，可修改 Git 地址与基准分支（右栏「项目概览」显示两者）。仅项目负责人、项目管理员或系统管理员可编辑，其他人只读。配置后，项目下的开发任务按分支开发：任务分支为 `feature/<任务编号>`，开始执行前为「待拉取」，开始执行时从基准分支拉取（「开发中」），审核通过、任务完成后合并回基准分支（「已合并到 <基准分支>」），任务取消则「已关闭」不合并。管理任务详情与开发板块任务详情都显示「代码分支」，状态按任务状态推导，原型不接真实 Git。
9. 删除未开始的任务：任务行「···」（及任务详情底部「···」）的「删除任务」，仅待规划 / 待开始且没有状态流转的任务可删，二次确认后删除，并清除其他任务对它的父任务、前序引用；研发任务沿用开发板块规则（待开始且未经历任何阶段）。仅项目负责人、系统管理员或任务创建人可见。行菜单浮在列表卡片之上，不被卡片边界裁切，空间不足时向上展开。
10. 删除项目：项目详情标题右侧「···」→「删除项目」，二次确认后删除；项目下的任务（管理任务与开发板块任务）和议题一并删除，不校验已有任务，返回项目列表，侧栏目录树同步隐藏该项目。

## 状态与异常

- 任务：待规划 / 待开始 / 已阻塞计入「待处理」；执行中、待审核、已完成、已取消按原状态显示。
- 未填任务名、研发任务无有效阶段、开发类项目缺 Git 地址或智能体团队时，就近提示并不保存。
- 右栏「会话权限（演示）」关闭后，任务行不再提供「在开发板块打开任务」，知识库只展示归档元数据。
- 项目成员：仅项目负责人、项目管理员或系统管理员可维护，其他人只读；项目负责人不能移除；有未完成任务（执行人、协作人或阶段执行人）的成员不能移除；项目至少保留 1 名成员；新加入成员的岗位按岗位标签默认推断，可在编辑菜单里调整。
- 重命名、删除项目：仅项目负责人或系统管理员可操作；不校验项目下是否已有任务，删除时任务一并清理，确认弹窗提示任务数量；确认时再次校验权限，变化则取消删除。
- 本地存储不可用时提示保存失败，不写入半条项目。

## 原型边界

管理项目、任务、议题保存在浏览器本地；项目管理员、项目目标与指令随项目保存在本地，项目管理员目前只影响项目管理权限；代码分支的拉取与合并只做状态展示。报完成、编辑任务、问灵基、在开发板块打开任务为演示提示，未接入真实执行与权限服务。

## 演示数据：设备巡检维修

「设备巡检维修系统建设」在 Manage 立项（负责人张工，交付智能体团队为苍穹应用开发智能体团队，仓库 `equipment-ops`，基准分支 main），是汇报 6.1 / 6.2 的贯穿项目。项目下的研发任务 T1001500–T1001506 在开发板块「协作开发 → 任务」里处理，任务详情显示所属项目；协作开发不再有项目页签。

## 下拉选择

普通单选字段复用共享下拉组件，统一箭头、面板、选中标记与单边框焦点状态；支持键盘选择、禁用项和空值选项（如「全部」或「无」）。现有搜索、多选选择器保留原有能力，归档页面不迁移。
