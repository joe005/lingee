# 数字员工与专家团

## 目标与分层

协作空间提供可使用的数字员工（专家）和专家团。列表按来源分为：**金蝶官方**、**企业自建**、**个人开发**；来源决定可编辑范围和安装方式。

- 金蝶官方：平台发布，客户端只读使用；发现新版本时卡片直接提示更新。
- 企业自建：由租户审核发布，租户成员可安装和更新。
- 个人开发：当前用户创建和编辑的草稿；提交审核后生成企业自建资产，个人稿仍保留，二者可并存。

## 数据业务关系

| 对象 | 关键字段 | 规则 |
| --- | --- | --- |
| 数字员工 | `assetId`、类型、来源、`tenantId`、名称、简介、头像 | 官方内容不绑定租户；企业自建必须绑定一个 `tenantId`；个人开发绑定创建人。 |
| 专家团 | `assetId`、来源、`tenantId`、成员快照、组长、阶段绑定 | 每个阶段可绑定一个或多个数字员工；发布时固定成员与阶段绑定的资产版本，成员单独更新不会改变已安装团队。 |
| 版本 | `versionId`、`assetId`、版本号、快照、更新说明 | 版本号自动递增且只读；版本快照不可修改。 |
| 本地安装 | `assetId`、安装版本、安装来源、安装时间 | 同一来源资产可安装多个版本，但客户端只启用一个当前版本。 |
| 审核提交 | `reviewId`、快照、提交人、目标租户、状态、原因 | 审核针对提交快照，不直接锁定个人草稿。 |

平台、租户和本地安装分别使用独立存储键；正式服务以资产 ID、租户 ID 和版本 ID 做唯一约束。

## 角色与权限

| 能力 | 普通成员 | 个人开发者 | 租户管理员 | 原厂管理员 |
| --- | --- | --- | --- | --- |
| 查看/安装官方资产 | 可 | 可 | 可 | 可 |
| 创建和编辑个人开发资产 | 可 | 本人可 | 可 | 可 |
| 提交企业审核 | 本人可 | 本人可 | 可 | 可 |
| 审核企业内容 | 无 | 无 | 仅本租户 | 原厂内容 |
| 发布/下架企业资产 | 无 | 无 | 本租户 | 官方资产 |
| 编辑已发布官方资产 | 无 | 无 | 无 | 可 |
| 查看历史版本/导出 ZIP | 已安装范围 | 本人范围 | 本租户 | 官方范围 |

预置/官方卡片不显示编辑和“复制为个人”；个人开发卡片先打开详情，点击“编辑”才进入 `expert-builder` 对话和统一侧栏。

## 客户端流程

- 数字员工和专家团页签共享搜索、来源筛选、胶囊式新增按钮和卡片布局。
- 云端数字员工和专家团默认按最近修改时间倒序排列，搜索和来源筛选沿用当前排序。
- 未安装企业资产显示“+”；点击安装时先校验依赖。
- 安装专家团时自动补齐缺失的企业数字员工成员；任一依赖安装失败则整体回滚并保留旧版。
- 已安装资产发现更高版本时直接在卡片显示“有更新”，打开更新说明后可更新全部。
- 更新失败保留旧版本、个人配置和会话历史。

## 创建、导入与提交

1. 点击“新增”进入对话，引用 `expert-builder`；创建专家团时根据职责描述推荐匹配的数字员工，以 AskUserQuestion 风格多选确认后生成结果卡片；点击卡片打开详情，个人开发详情点击“编辑”才进入右侧对话配置。
2. 导入 ZIP 仅模拟解析和扫描，不读取实际文件；确认头像、名称、简介后保存为草稿。
3. 新资产直接保存草稿；已存在资产要求填写更新说明并自动生成下一个只读版本。
4. 编辑页提交审核；企业自建目标由当前租户确定，个人开发稿仍可继续编辑。
5. 审核通过后上架；驳回时才显示必填原因。驳回不生成可安装版本。

## 专家团发布规则

- 成员必须引用已发布或待发布的数字员工版本，且组长必须是成员。
- 发布时写入成员版本快照；后续成员更新需重新提交专家团版本。
- 每个交付阶段展示绑定的数字员工，可绑定一位或多位；未配置时按数字员工工作模式自动补齐默认绑定。
- 专家团编辑的交付阶段采用左侧阶段树、右侧阶段详情布局；保存、提交审核和测试位于编辑区右上角。
- 下架被已上架专家团引用的数字员工时，提示引用关系并阻止下架；无真实引用时允许下架，历史版本保留。

## 状态机

草稿 → 待审核 → 已上架 → 已下架；待审核可驳回，驳回回到草稿。已上架产生更新时进入新的草稿/待审核链路，旧上架版本持续可用。

## 用户旅程

个人开发者新增数字员工 → 对话生成并编辑 → 提交企业审核 → 租户管理员查看快照并通过/驳回 → 通过后进入更多数字员工 → 成员点击“+”安装 → 发现新版本时查看更新说明并整体更新。创建专家团时选择成员版本 → 安装团队自动补齐依赖 → 团队固定使用成员快照。

## 原型边界

云端目录、扫描、审核、安装、更新和依赖补齐均为浏览器本地持久化模拟；不代表真实云端分发、包安全扫描或跨设备同步。
