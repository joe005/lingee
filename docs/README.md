# Lingee 功能需求文档

这些文档描述当前原型的目标、入口、交互和状态。实现以源码和当前用户要求为准；文档用于保持交互口径一致，不代表已接入真实服务。

账号菜单不再提供「更新日志」入口，原独立页面不再展示；旧 `/changelog` 链接和历史停留记录回到默认新会话页面。

开发侧栏的静态会话示例仅保留“采购订单管理应用开发”；新增会话仍按现有会话流程进入列表。

旧 `/tasks` 链接、上次停留的任务地址及内部任务跳转统一进入协作开发的任务页签，保留顶部任务／智能体／智能体团队导航，不再打开无一级页签的独立任务页面。

侧栏「协作开发」不展示任务数量角标；任务页状态页签内的数量统计保留。

侧栏顶部工具区提供「待办」（进入独立待办页）、「消息通知」（打开居中通知弹窗）与收起侧栏，悬停和键盘聚焦显示下方提示；品牌与顶部工具区位于同一行，搜索入口在项目标题旁。底部显示当前账号与角色，「反馈」沿用帮助中心链接，文件夹入口选择本地目录并提示名称，原型不读取或上传目录内容。

## 更新规则

交互、状态、入口或权限变化时，修改对应模块文档；纯样式调整不强制更新。文档采用短段落和表格，避免记录实现流水账。

新会话首页按最新截图采用 720px 输入区、衬线标题、工作区托盘和六个快捷入口；模型默认选中「专家」。未选中智能体时，从「＋ → 选择智能体 / 智能体团队」打开选择器，选中后工具栏显示对象，可再次点击更换。首页提示语为「布置开发任务，输入 / 调用技能或命令」；斜杠不新增指令解析能力，仍沿用现有输入与发送逻辑。

会话页顶栏按真实版补齐「打开方式」（主按钮在当前应用中打开工作区，下拉切换 Finder、VS Code、终端并记住选择）以及「审查」「文件树」「Wiki」入口，保留历史版本与预览开关；原型不读取本地工作区，这些入口只给出结果提示。会话输入框提示语与真实版一致，为「布置开发任务，输入 / 调用技能或命令」。每轮回复完成后显示回复尾：复制回复、重新生成（任务会话不提供）、分叉到新会话、分享，并显示「执行方 · 模型 · 耗时」和本轮点数消耗；分叉与分享为演示提示，历史回复的耗时按正文长度估算。

开发侧栏不显示「最近会话」分组，仅按项目展示会话；已有未归属项目的会话数据保留，不在侧栏单列。工作板块的历史对话保持原有入口。

ERP 环境的 OAuth 授权信息卡中，「授权范围」固定显示普通文本「应用开发API权限」，不展示 API 权限数量，不提供链接或权限明细展开入口。该规则适用于编辑和查看环境；授权时间统一显示为 `YYYY-MM-DD HH:mm:ss`，新授权及重新授权成功时记录实际授权时间，未授权时不生成时间。ERP 授权确认页沿用现有权限清单。

新增 ERP 环境依次展示「基本信息 → 授权类型 → 连接配置」。基本信息只含同行的环境名与地址；新增时不展示创建第三方应用、获取 ID 和密钥的说明；两张选择卡以单选圆点和描边标识选择。第三方应用模式的连接配置中，环境类型与数据中心同行，数据中心标签旁提供刷新图标（加载时禁用并显示加载状态）；应用 ID 与密钥同行，网关标识占整行，「配置指导」位于连接配置标题行右侧。关闭代理用户控制、添加当前用户并赋予开发权限的提示在标题下方独立展示为带警示图标的浅色提示条；窄窗口改为单列并允许说明换行。OAuth 模式仍在 ERP 授权页选择数据中心。

ERP 环境列表不展示「第三方应用」标签；OAuth 环境继续展示授权状态及需要重新授权的入口；失效时标签显示「OAuth授权已失效」，不再展示下方失效原因说明，保留「重新授权」按钮。本地、云端和默认标签保持原有规则。

ERP 连接配置的编辑与查看弹窗在「取消／关闭」与「保存」之间提供「测试连接」：OAuth 仅授权有效且曾授权成功时显示；新增、未授权、授权失效或已断开时不显示。已有第三方应用连接保留测试入口。测试期间按钮显示「测试中…」并禁用，完成后提示结果；关闭或切换环境会取消未完成的测试。当前为本地模拟，不发送真实 ERP 请求，也不保存表单。
