# Lingee 功能需求文档

这些文档描述当前原型的目标、入口、交互和状态。实现以源码和当前用户要求为准；文档用于保持交互口径一致，不代表已接入真实服务。

账号菜单不再提供「更新日志」入口，原独立页面不再展示；旧 `/changelog` 链接和历史停留记录回到默认新会话页面。

开发侧栏的静态会话示例仅保留“采购订单管理应用开发”；新增会话仍按现有会话流程进入列表。

旧 `/tasks` 链接、上次停留的任务地址及内部任务跳转统一进入协作开发的任务页签，保留顶部任务／智能体／智能体团队导航，不再打开无一级页签的独立任务页面。

侧栏「协作开发」不展示任务数量角标；任务页状态页签内的数量统计保留。

侧栏顶部工具区提供「待办」（进入独立待办页）、「消息通知」（打开居中通知弹窗）与收起侧栏，悬停和键盘聚焦显示下方提示；品牌与顶部工具区位于同一行，搜索入口在项目标题旁。底部显示当前账号与角色，「反馈」沿用帮助中心链接，文件夹入口选择本地目录并提示名称，原型不读取或上传目录内容。

## 更新规则

交互、状态、入口或权限变化时，修改对应模块文档；纯样式调整不强制更新。文档采用短段落和表格，避免记录实现流水账。

新会话首页按最新截图采用 720px 输入区、衬线标题、工作区托盘和六个快捷入口；模型默认选中「专家」。未选中智能体时，从「＋ → 选择智能体 / 智能体团队」打开选择器，选中后工具栏显示对象，可再次点击更换。首页提示语为「布置开发任务，输入 / 调用技能或命令」；斜杠不新增指令解析能力，仍沿用现有输入与发送逻辑。

开发侧栏不显示「最近会话」分组，仅按项目展示会话；已有未归属项目的会话数据保留，不在侧栏单列。工作板块的历史对话保持原有入口。
