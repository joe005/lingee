## 6.1 Build 让专业开发人员工作更轻松

**一句话场景**：张伟在协作开发里把金蝶 ERP 上的「设备巡检维修系统」交给苍穹应用开发智能体团队，需求、设计、编码、测试、部署由智能体执行，编码实现由苍穹元数据智能体生成实体、表单、插件元数据，张伟只在每个阶段审核产物。

**一句话客户价值**：重复的编码、测试和部署交给智能体团队，专业开发人员只做判断和把关，一套 ERP 业务系统几天就能交付上线。

**金蝶独特价值（元数据）**：效率更高（实体、表单、插件都是元数据，智能体按元数据生成和修改）；Token 消耗更少（读写结构化元数据而不是整段源代码）；安全性（元数据自带类型与校验规则，权限沿用金蝶 ERP）。

## 6.2 Build 让非专业开发人员都可构建自己的智能体

**一句话场景**：设备巡检维修系统上线后，设备主管周建国在同一个协作开发项目里提新任务，用大白话讲出排障经验；「智能体开发」交付「设备故障诊断助手」，通过 MCP 接上刚上线的系统，排障手册上传为内置知识；测试通过后在配置面板里提交上架审核，设备部的维修工程师陈志远在「工作」里直接提问。

**一句话客户价值**：协作开发不只交付应用，也能交付智能体，并直接用上前面交付的系统；懂业务就能做智能体，老师傅的经验和系统数据连在一起。

全程留在协作开发，接在 6.1 部署之后，体现「同一项目先交付系统、再交付用系统数据的智能体」。
