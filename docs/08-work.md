# 工作

## 目标与范围

工作板块面向日常办公与业务办理，入口是侧栏顶部「工作」页签。本期开放「新任务」首屏及顶部独立待办页；定时任务、智能体、技能、发现、历史对话详情保留入口，点击提示「不在本次演示范围」。

## 入口

- 侧栏顶部页签：工作 / 管理 / 开发。切到「工作」后侧栏只显示工作菜单，主区打开「新任务」。
- 工作菜单：新任务、定时任务、智能体、技能、发现；其下为「历史对话 / 定时任务」页签、搜索和对话列表（默认分组）。
- 地址：`/work`，刷新后还原。

## 待办与消息通知

- 顶部「待办」打开 `/todos`，不跳转开发任务页。页头为“待办”，左侧是待处理、已处理页签及数量，右侧是业务维度和日期范围。支持页签切换、日期选择及清空；尚未接入办公业务审批数据，两项数量均为 0，显示对应空状态，不把开发任务或未读消息当成待办。
- 顶部铃铛打开 720×640px 居中“消息通知”弹窗，带遮罩、关闭按钮及全部／通知／其他分段页签。沿用现有通知数据与权限：无任务关联的系统消息归为通知，任务关联消息归为其他；无数据时显示收件箱图标和“暂无通知”。点击任务消息标记已读，进入协作开发的任务页签并打开对应详情，保留任务／智能体／智能体团队导航；收件箱详情的“打开任务”使用同一路径。
- 通知弹窗支持关闭按钮、遮罩和 Esc 关闭，键盘焦点限制在弹窗内；关闭按钮或 Esc 关闭后焦点返回铃铛。通知数据仍是本地原型数据，不连接生产消息服务。

## 新任务首屏

1. 问候语「灵基一动，工作轻松」，下方场景页签：日常办公、业务分析、业务执行。切换场景会更换输入框提示和快捷入口。
2. 输入框：文本区，工具行含添加附件、@ 选择对象、选择智能体、模型（自动 / 快速 / 专家 / 深度）、语音输入和发送。添加附件、@、语音为演示占位。
3. 输入框下方灰色托盘中的「选择分组」，用于指定对话归属分组（默认分组）。
4. 快捷入口：点击后把入口名预填进输入框。
5. 发送（Enter，Shift + Enter 换行）后，任务以前 24 字作为标题加入历史对话顶部，并提示已发起；输入为空时发送按钮置灰。
6. 「选择智能体」列表顶部是已发布的智能体（设备故障诊断助手、问卷调研助手、费报智能体）。选中其一后发送，进入智能体对话页：标题为问题前 24 字，回答先显示思考与技能调用摘要，再给正文、参考来源和时间；页内可切换智能体继续提问。设备故障诊断助手问注塑机温度类问题时，回答引用设备巡检维修系统里的维修记录。

## 历史对话

- 「历史对话」列出对话，右侧搜索图标展开搜索框按标题过滤；「定时任务」页签暂无数据，显示空态。
- 点击历史对话提示「不在本次演示范围」。

## 原型边界

对话内容、执行与历史只在页面内存中模拟，刷新后恢复演示数据；未接入真实智能体与模型。

## 下拉选择

普通单选字段复用共享下拉组件，统一箭头、面板、选中标记与单边框焦点状态；支持键盘选择、禁用项和空值选项（如「全部」或「无」）。现有搜索、多选选择器保留原有能力，归档页面不迁移。
