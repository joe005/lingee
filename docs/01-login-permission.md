# 登录与权限

## 目标

用演示账号切换不同用户视角，控制协作开发、租户管理和原厂管理的可见与可操作范围。

## 入口与状态

- 未登录：显示登录页，登录成功后进入上次可用页面。
- 已登录：侧栏显示当前姓名、角色和账号菜单。
- 原厂管理员：可进入原厂管理并审核发布官方内容。
- 租户管理员：可进入租户管理，查看和审核本租户提交。
- 普通协作成员：可使用有权限的项目、任务和智能体能力。
- 协作人员可直接使用姓名登录；未单独设置密码时，初始化密码为 `lingee520`。
- 登录后直接进入当前原型的默认页面。

## 关键流程

登录 → 识别账号角色 → 恢复可访问页面 → 按权限展示操作按钮。退出或切换账号后清理当前账号的编辑状态，不泄露上一账号数据。

## 原型边界

账号、角色和数据权限由浏览器本地演示数据模拟；正式版本需要服务端鉴权、租户隔离和审计。
