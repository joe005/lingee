# 工作区人员与角色

## 层级与职责

- **系统管理员**是工作区级角色，可以维护工作区设置、人员、人员导入与同步配置、系统集成。一个工作区可以有多名系统管理员，不能移除或降级最后一名系统管理员。
- **项目经理**是工作区级角色，负责发起项目。普通工作区成员不能创建项目。
- **项目负责人、项目成员**是项目中的身份。项目经理创建项目后默认担任该项目负责人；项目经理或项目负责人可编辑项目资料、添加和移除项目成员，其他人只能查看这些内容。项目成员从工作区人员中添加，添加后默认为成员。
- 工作区角色和项目负责人身份分别存储。系统管理员不因其工作区角色自动成为所有项目的成员；项目负责人也不因其项目身份获得整个工作区的设置权限。系统管理员可以创建项目，但创建后也须指定具体负责人。
- 项目列表按当前用户提供“我负责的 / 我参与的”视角。“我负责的”指担任项目负责人；“我参与的”指加入了项目但不是负责人。项目列表仍可按工作区筛选。
- 项目列表和卡片只展示字段；有权限的人进入项目详情后编辑。变更项目负责人须展示原负责人和新负责人，确认后才保存，取消时保持原值。

## 人员主数据

人员属于工作区，项目以人员 ID 引用人员。姓名不是身份标识；需保存稳定的内部人员 ID，并对接外部系统人员 ID。邮箱、手机号可用于邀请和人工查找，但不能单独充当同步主键。

### 文件导入

系统管理员可导入人员文件。原型首期支持 CSV；正式版可扩展 XLSX。字段至少包含姓名及邮箱或手机号；可选部门、外部人员 ID。导入前展示新增、更新、跳过、冲突数量及明细，经确认后写入。重复导入按外部人员 ID 优先、邮箱或手机号辅助匹配；同名不自动合并。导入不改写项目成员关系和工作区角色。

### 金蝶组织/人员系统同步

同步来源为金蝶组织/人员系统。由系统管理员配置连接并触发首次同步；后续可手动同步，定时同步在服务端能力具备后启用。同步按外部人员 ID 增量更新姓名、部门、邮箱、手机号和在职状态，记录上次同步时间、结果、成功与失败数量及错误明细。

外部离职或停用人员先标记为停用，不直接删除人员或其历史任务；有待处理任务时提示管理员先转交。同步不覆盖手工设置的系统管理员角色和项目角色，也不自动把人员加入项目。外部接口、鉴权方式、字段映射、变更游标和停用状态的具体口径需与金蝶组织/人员系统确认后实现。

## 原型与正式接入边界

当前单文件原型的人员数据存于浏览器，演示角色与项目角色尚未形成完整权限校验。文件导入可在原型内实现；金蝶组织/人员系统自动同步需要服务端连接、鉴权和接口支持。在接口接通前，界面应明确标注“待接入”，不能展示虚假的同步成功状态。
