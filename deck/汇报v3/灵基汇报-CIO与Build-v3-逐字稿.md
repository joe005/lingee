## 第 3 页 · 6.1 Build 让专业开发人员工作更轻松

**页面文字**

- 灵基Build For 专业开发人员
- 6.1 Build 让专业开发人员工作更轻松
- 客户价值：重复的编码、测试和部署交给智能体团队，专业开发人员只做判断和把关，一套 ERP 业务系统几天就能交付上线。
- 金蝶独特价值 · 元数据：
  - 效率更高：标准表单、列表由元数据直接生成 → 智能体只交付这个系统特有的部分
  - Token 消耗更少：交付物是结构化元数据 → 读写只加载相关部分，不加载整套源代码
  - 安全性：类型、校验写在元数据里 → 权限沿用金蝶 ERP

## 第 4 页 · 6.2 Build 让非专业开发人员都可构建自己的智能体

**页面文字**

- 灵基Build For 业务人员
- 6.2 Build 让非专业开发人员都可构建自己的智能体
- 客户价值：懂业务就能做智能体，老师傅的经验不写代码就能沉淀，维修工程师遇到故障也能按老师傅的思路排查。
- Build 怎么做出一个智能体：
  - ① 说经验：用大白话讲清楚要做什么、老师傅怎么排查
  - ② Build 生成：经验写成工作原则；挂上通过 MCP 查系统数据的技能；放进排障手册
  - ③ 先测再上架：Console 沙箱里测试，不碰生产数据；提交后经管理员审核，进入生产环境
