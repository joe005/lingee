Build 交付工单管理系统

场景吴宏超在协作开发「客户服务工单平台」项目里把工单管理系统拆成任务交给智能体团队，上线后员工提单、IT 服务台按 SLA 处理。
客户价值项目风险当天可见，系统交付周期从 12 周缩短到 6 周；工单一次填全、时限透明、全程留痕。
提单 · 一次填全

分类、优先级、附件一次填全

员工按分类和优先级提交工单，
截图和日志随单上传，少一轮来回追问。

价值：服务台拿到工单就能处理。
SLA · 时限透明

提交时就知道多久响应

按优先级自动给出响应和解决时限，
处理中、待评价、本月解决一屏可见。

价值：处理时限有据可依，超时可追。
跟踪 · 闭环评价

进度可查，解决后评价

每张工单有编号和状态，处理到哪步都可查，
解决后由提单人评价，常见问题先自助排查。

价值：工单全程留痕，服务质量可度量。

Build 让非专业开发人员都可构建自己的智能体

场景工单系统上线后，IT 服务台主管在同一项目提新任务，交付 IT 服务台助手：先查知识库，查不到就经 MCP 自动提工单。
客户价值懂业务就能做智能体；常见问题员工自助解决，解决不了的自动进工单，服务台少接重复咨询。
同一项目 · 新任务

大白话写要求，不写代码

杨帆在同一个项目里写下：先查知识库，
查不到就帮员工提工单，交给「智能体开发」。

价值：懂业务就能做智能体。
交付智能体 · 知识库 + MCP

先查知识库，再接工单系统

处理顺序写进配置：知识库命中就回答，
未命中经 MCP 调用工单系统提单。

价值：知识库和工单系统连在一起。
使用 · 查不到自动提单

查不到，工单卡片直接弹出

知识库没有答案时，助手填好工单，以 MCP UI
卡片弹出，分类、优先级、SLA 已带好，确认即提交。

价值：问题一次说清，直接进工单。
