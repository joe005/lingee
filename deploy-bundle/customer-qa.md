## 问答明细

### 1. 计划优先部署到哪个腾讯云地域？这会影响价格查询和备案判断。

- 问题 ID：`deployment_region`
- 推荐选项：广州（ap-guangzhou）
- 用户选择：广州（ap-guangzhou）
- 用户备注：按推荐选择广州

| 选项 | 说明 |
| --- | --- |
| 广州 `ap-guangzhou` （用户选择） | 华南常用默认地域；绑定域名对外服务时通常需要备案。 |
| 上海 `ap-shanghai`  | 华东常用地域；绑定域名对外服务时通常需要备案。 |
| 北京 `ap-beijing`  | 华北常用地域；绑定域名对外服务时通常需要备案。 |
| 中国香港 `ap-hongkong`  | 通常不需要 ICP 备案，但价格、延迟和可售规格要单独确认。 |

### 2. 这次上云最优先考虑什么？

- 问题 ID：`deployment_priority`
- 推荐选项：稳定优先（balanced）
- 用户选择：稳定优先（balanced）
- 用户备注：按推荐选择稳定优先

| 选项 | 说明 |
| --- | --- |
| 稳定优先 `balanced` （用户选择） | 推荐方案会优先照顾长期运行、备份和后续小幅扩容。 |
| 成本最低 `lowest_cost`  | 倾向最小方案，先用较少资源把服务跑起来。 |
| 扩展性优先 `high_scalability`  | 倾向高扩展性方案，为更多访问量和分层扩容预留空间。 |

### 3. 你预计上线初期的访问量级接近哪一种？

- 问题 ID：`traffic_expectation`
- 推荐选项：真实用户（real_users）
- 用户选择：真实用户（real_users）
- 用户备注：按推荐选择真实用户

| 选项 | 说明 |
| --- | --- |
| 个人/小范围 `small`  | 适合最小方案或较轻量推荐方案。 |
| 真实用户 `real_users` （用户选择） | 建议用推荐方案，留出备份、磁盘和排障空间。 |
| 增长明确 `growth`  | 需要考虑高扩展性方案，入口、应用、数据分层。 |

### 4. 生产部署所需信息现在准备到什么程度？

- 问题 ID：`production_inputs`
- 推荐选项：部分缺失（partial）
- 用户选择：部分缺失（partial）
- 用户备注：按推荐选择部分缺失

| 选项 | 说明 |
| --- | --- |
| 基本齐全 `ready`  | 已准备生产环境变量、域名/DNS 和代码交付方式。 |
| 部分缺失 `partial` （用户选择） | 可以先出部署报告，购买或上线前补齐。 |
| 还未准备 `not_ready`  | 只适合先做方案评估，不应直接购买部署。 |
